# 📊 Customer Churn Analysis



## 🔎 Overview
This project analyzes **customer churn patterns** using a cleaned dataset and an interactive dashboard. It provides insights into customer retention, churn rates, and revenue distribution across demographics, subscription types, and payment methods.




## 📂 Dataset
- **Total Customers:** 308  
- **Churn Customers:** 83  
- **Retained Customers:** 225  
- **Churn Rate:** 26.95%  
- **Total Revenue:** 14.75M  
- **Average Monthly Charges:** 1.37K  
- **Average Tenure:** 34.41 months  





### Key Features
- Demographics: Age, Gender, State, City, Senior Citizen flag  
- Subscription: Tenure groups, Contract type, Internet service, Tech support  
- Billing: Monthly charges, Total charges, Payment method  
- Churn Indicators: Churn flag, Last interaction date  





## 📊 Dashboard Insights
- **Revenue by State:** Gujarat (3.5M), UP (3.3M), Delhi (3.0M), Karnataka (2.6M), Maharashtra (2.4M)  
- **Churn by Contract Type:** Month‑to‑Month highest (~60), One Year lowest (~10)  
- **Churn by Internet Service:** Cable (31.3%), 5G (26.5%), Fiber (22.9%), DSL (19.3%)  
- **Churn by Payment Method:** UPI (27.7%), Debit Card (19.3%), Net Banking (18.1%), Credit Card (13.3%), Cash (2.4%)  




## 🎯 Use Cases
- Predict churn using **Machine Learning models**  
- Perform **Exploratory Data Analysis (EDA)** for customer behavior  
- Build dashboards in **Power BI / Tableau**  
- Feature engineering for **classification algorithms**
